## 🚀 Getting Started
Once you have downloaded the application, follow these steps to start using it:

1. **Locate the Downloaded File**: Open the folder where your downloads are saved. You should see a file named something like `verl-recipe.zip`.

2. **Unzip the File**: Right-click on the `verl-recipe.zip` file and select “Extract All.” Choose a destination folder where you want to keep the application files.

3. **Open the Application**: In the folder where you extracted the files, double-click on `verl-recipe.exe` (or the equivalent file for your operating system).

4. **Follow On-Screen Instructions**: A welcome window will appear. Just follow the on-screen instructions to set up the application.

5. **Select a Recipe**: Once the application opens, click on a recipe from the menu. You can find various example scenarios to explore.
